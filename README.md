### Day 1 Workshop: Streamlit Application

A lightweight web application built using Python and Streamlit during the Day 1 workshop session. This project demonstrates how to set up a virtual development environment and deploy an interactive web interface. 

### 🛠️ Project Setup & Installation

Follow these steps to run the application locally on your machine: 

1. **Clone the repository:** 

bash

git clone https://github.com/vinayshankar-rgb/Day-1-Work.git
cd "Day1 workshop"

Use code with caution.
2. **Activate the virtual environment:** 

  * **Windows (PowerShell):** 

powershell

.env\Scripts\Activate.ps1

Use code with caution.
  * **macOS / Linux:** 

bash

source .env/bin/activate

Use code with caution.
3. **Install dependencies:** 

bash

pip install streamlit

Use code with caution.

### 🚀 How to Run the App

Launch the local development server using the following command: 

bash

streamlit run app.py

Use code with caution.

### 📁 Repository Overview

* **app.py**: The primary application file containing the production Streamlit code, UI components, and interactive logic.
* **demo1.py**: A playground/testing script used during the initial workshop steps to practice Python syntax and experiment with baseline Streamlit functionalities.
* **.gitignore**: Configuration file designed to prevent tracking massive local dependencies (.env/) and editor configurations (.vscode/), keeping the repository lean.
